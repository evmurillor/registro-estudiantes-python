# Registro de estudiantes en Python

## Descripción

Programa desarrollado para gestionar estudiantes y calificaciones utilizando un diccionario como estructura de colección de datos.

## Funcionalidades

- Agregar estudiantes.
- Mostrar estudiantes registrados.
- Buscar estudiantes.
- Eliminar estudiantes.

## Lenguaje utilizado

Python 3
